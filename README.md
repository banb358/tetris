# Cyber Tetris 🎮

ネオンカラーが特徴的な、サイバーパンク風のテトリスゲームです。
PCでもスマホでも快適に遊べます。

## 公開URL
(ここにGitHub PagesのURLを記載してください)

## 特徴
- ✨ **サイバーデザイン**: ネオンブルーとピンクのスタイリッシュな視覚効果
- 📱 **モバイル対応**: タッチ操作用のボタンを搭載
- 🚀 **快適な操作性**: ハードドロップやソフトドロップに対応

## 操作方法

### PC (キーボード)
- `←` `→`: 移動
- `↑`: 回転
- `↓`: ソフトドロップ
- `Space`: ハードドロップ (一気に下へ)
- `Esc`: ポーズ

### スマホ (タッチボタン)
- `←` `→`: 移動
- `↻`: 回転
- `↓`: ソフトドロップ
- `HARD DROP`: ハードドロップ (一気に下へ)
